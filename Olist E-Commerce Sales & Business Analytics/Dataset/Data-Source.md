## Data Source

This project uses the publicly available **Olist Brazilian E-Commerce Dataset** from Kaggle.

- **Dataset:** [Olist Brazilian E-Commerce Dataset](https://www.kaggle.com/datasets/olistbr/brazilian-ecommerce)
- **Source:** Kaggle

The dataset contains information about orders, customers, sellers, products, payments, reviews, and geolocation.

**Note:** The original dataset files are not included in this repository due to their large file size.
