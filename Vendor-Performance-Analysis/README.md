# 📊 Vendor Performance Analysis using Python and Power BI

## 📌 Project Overview

This project focuses on analyzing vendor performance, sales trends, purchasing patterns, and profitability using Python and Power BI.

The analysis involves data ingestion, data cleaning, Exploratory Data Analysis (EDA), automated vendor summary generation, and interactive dashboard development. The objective is to identify business opportunities, evaluate vendor contributions, optimize inventory management, and support data-driven decision-making.

## 🎯 Business Problem Statement

Effective inventory and sales management are critical for optimizing profitability in the retail and wholesale industry. Businesses need to ensure they are not incurring losses due to inefficient pricing strategies, poor inventory turnover, excessive holding costs, or vendor dependency.

The goal of this analysis is to:

- Identify underperforming brands that require promotional or pricing adjustments.
- Determine top-performing vendors contributing to sales and gross profit.
- Analyze the impact of bulk purchasing on unit costs.
- Assess inventory turnover to reduce holding costs and improve operational efficiency.
- Investigate profitability across vendors and brands to identify opportunities for improving profit margins.

## 🚀 How to Run

1. Clone this repository:

   ```bash
   git clone https://github.com/Bhagyashreekatale1/Data-Analyst.git
   ```

2. Navigate to the project directory:

   ```bash
   cd Data-Analyst/Vendor-Performance-Analysis
   ```

3. Open the Jupyter notebooks from the `Notebooks/` folder to explore the data and perform vendor performance analysis.

4. Run the Python scripts from the `Scripts/` folder for data ingestion and vendor summary generation.

5. Open `vendor_performance.pbix` from the `Dashboard/` folder using Microsoft Power BI Desktop.

6. Review the final business insights in the `Reports/` folder.
